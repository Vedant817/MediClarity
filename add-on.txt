2) Critical Quality Fixes Required First (P0)
==================================================

- Fix API authorization model:
  Derive user identity from Clerk auth/session on server side for all sensitive endpoints.
  Do not trust userId sent via query/body for protected data access.

- Fix runtime incompatibility:
  Remove Edge runtime where MongoDB/Mongoose is used.

- Fix appointment model integrity:
  Add and enforce followUpSent (or equivalent) in schema to prevent duplicate follow-up notifications.

- Unify scheduling time handling:
  Standardize date/time format across UI, DB, and availability APIs.
  Remove stale hard-coded 2025 mock availability.

- Improve AI safety/reliability prompts:
  Remove instructions that force answering without enough context.
  Add uncertainty handling and safe escalation language.

- Replace in-memory chat session state:
  Persist conversation/session state in DB or Redis.

- Fix broken/placeholder UI paths:
  Complete profile page and implement/remove settings route link.

- Quality gates:
  Install dependencies, restore lint pipeline, add test coverage, and run checks in CI.
